Connect your CRM

Bring your customers and jobs into Portfolio automatically, and get hail hits written straight back onto the record in your CRM, so your team sees them where they already work. Synced records refresh every 6 hours.

CRM integrations are included with paid plans. Upgrade to connect.

JobNimbus Not connected

Imports your JobNimbus contacts (with their property address) into Portfolio. When one is hit by hail, we add a note to that contact with the hail size, date and a link to the full storm report.

Where do I get a JobNimbus API key?
  1. Log in to JobNimbus as an admin.
  2. Open Settings → API and create a new API key.
  3. Give it an access profile that can see all contacts, then copy the key.

AccuLynx Not connected

Imports your AccuLynx jobs (job location address) into Portfolio. When a job's property is hit by hail, we post a message on the job with the hail size, date and a link to the storm report. Cancelled jobs are skipped.

Where do I get an AccuLynx API key?
  1. An AccuLynx admin opens Account Settings and finds API Keys.
  2. Create a key and copy it. Keys are per location, so connect one location's key here.
  3. If you don't see API Keys, ask AccuLynx support to enable API access for your account.

Zapier, Make & other CRMs Not connected

Works with ClaimWizard, HubSpot, SPOTIO, Salesforce and any CRM on Zapier or Make. We send an event every time a Portfolio property is hit, and you can send new clients into Portfolio.

Set up with ClaimWizard (via Zapier)
  1. Clients into Portfolio: new Zap → trigger ClaimWizard: New Client Added → action Webhooks by Zapier: POST to the link above, mapping name, address, city, state and ZIP.
  2. Hail hits into ClaimWizard: new Zap → trigger Webhooks by Zapier: Catch Hook → paste the hook URL in "Send hail hits" above → action ClaimWizard: Create Lead, mapping property.name, property.address and summary into the note.
  3. Click Send test event so Zapier sees a sample before you map fields.

Webhooks by Zapier needs a paid Zapier plan. Make (make.com) works the same way with its Webhooks module.
